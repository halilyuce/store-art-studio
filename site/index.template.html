One rule before anything else

Never launch your real app to take a screenshot. An app that syncs state can overwrite real keychains and saved data. This pipeline renders views from sample data in a test bundle with no host app.

2

Create a unit test target with no host app

Xcode: File, New, Target, Unit Testing Bundle, named StoreArt. In General set Host Application to None. That is what makes it safe: no app is installed or launched. Set its minimum deployment target to iOS 18 (the page background uses MeshGradient).

3

Give it the views you want to render

  • Add StoreArt/*.swift to the new target.
  • Add the Swift files of the screens, widgets or activities you want in screenshots to the target's membership.
  • Do not add your @main app entry point, or anything that touches the Keychain or a live account.
  • Add your Localizable.strings and asset catalogs to its resources, then enable StoreArt.forwardMainBundle() in setUp.
!
Adding files means editing project.pbxproj

By hand: a file reference, a group entry, a build file and a Sources entry per file, with fresh 24-character hex ids. Build after each edit. Do not use the xcodeproj gem, it re-sorts the file and can drop entries. Or ask Claude to hand-edit the pbxproj for you.

4

Edit the StoreArt scheme, Test, Arguments, Environment Variables: TZ = America/Chicago, or change StoreArt.timeZone in StoreArtKit.swift. The test fails on purpose when the two disagree, so a clock never drifts.

The review loop

Before any render reaches you, the agent does this every time.

1. Look

Open the PNG, then look again at about 300 px wide. If the point of the slot is gone, it fails.

2. Measure

With a reference: compare.swift puts reference and render side by side with shared guides. probe.swift measures colours, ink bounds and text rows.

3. List and fix

Every difference by category: palette, type, margins, pill, device, depth, light, empty areas. Fix and repeat until minor.

Hard rules

What the skill enforces, whatever you ask
Never launch your real app
Render views in a host-less test bundle on a dedicated simulator that never has the app installed. Apps that sync state can overwrite real keychains and saved user data.
UI is real code
If a view cannot render host-less, it is redrawn at the app's own point sizes from the same payloads, and you are told which screens are redraws.
Never shrink a headline
One pixel size in every slot and language. When a wording is too wide, shorten the wording. A width test enforces it.
One market first
Render the default market, get approval, then roll out. Never all locales unprompted.
Approved chrome is frozen
The status bar, bezel metrics and Lock Screen are shared by every slot. Changing one silently restyles slots you already approved.
Exact exports
Right pixel size, opaque PNG, no alpha, checked by verify-export.sh.
Provenance
Every generated asset gets a .txt: model id, prompt, seed, generation id, credits.
Spend deliberately
Balance checked, cost preflighted, and a question before any gate costs more than your budget (default 40 credits).
Copy is transcreated
Each locale is written as if authored there, marked "not native-reviewed", and you are asked which languages you can review.
No borrowed identity
No real people or brands you do not own, no third-party icons, no AI-generated Apple hardware. Claims such as user counts or awards only when you supply and can back them.
Licensed inputs stay out of git
Apple bezels and provider images are gitignored and re-fetched by script.
Match craft, never content
A reference set teaches composition, rhythm and finish. Its brand, copy, icons and photography are never copied.
No em dashes
Not in copy, comments or messages. They read as machine writing, and in store copy that costs conversions.

Troubleshooting

When something looks wrong
Strings print as raw keys

Bundle.main is the test runner. Call StoreArt.forwardMainBundle() in setUp and add your Localizable.strings to the target's resources. Overriding localizedString alone fixes .localized but not Text("key").

"Font ... did not register"

The PostScript name in StoreArtFace does not match the file. Check it with UIFont(name:size:). Use static font instances, not variable fonts.

"The process runs in ... but StoreArt.timeZone is ..."

Set TZ in the StoreArt scheme's test environment, or change the constant.

A widget has no background, or a progress bar is a yellow box

containerBackground draws nothing host-less, so the template paints the tile itself. A UIKit-backed ProgressView needs a custom ProgressViewStyle. Frosted materials do not blur; .blur does.

Xcode complains about a stale module cache after render.sh

render.sh uses its own build/StoreArtDerivedData. Do not point it at Xcode's DerivedData.

The phone is a plain dark frame

The bezel PNG is missing or named differently from BezelSpec.name.

The whole slot shifts when I add one layer

A placed(x:) at a negative or oversize position widens the ZStack. Use .placed(x: 0, y: 0).offsetPx(...) for anything that starts off the canvas.

Paparazzi will not build

Paparazzi releases pin a Gradle, compileSdk and JDK range. Check the release notes against your build before upgrading either.

A font silently falls back

Bundle static TTFs and assert in a test that each face loaded, the way the iOS template does with verifyRegistered.

Text moves between locales or devices

Pin Density and fontScale = 1.0 in the test and place text by baseline, not by top edge.

The screen looks short or cramped in the slot

Render the app composable at a realistic phone size (about 412 x 915 dp) and scale it into the device frame. Do not lay it out in the 360 x 640 dp slot.

A screen needs a ViewModel, network or a login

Give it a fake and sample data. If that cannot be done, tell the agent to redraw that screen at the app's own sizes from the same payloads, and expect it to say so.

A headline does not fit in some language

Never shrink the type. Shorten the wording: a shorter synonym, a shorter structure, or drop the lead word. The width test exists to enforce this.

Higgsfield calls are not available

Run /mcp, authenticate, and restart the session.

A red subject turned brown after keying

The default despill removes the key colour's direction. Key it with --spill 0, or generate it on solid green.

Copy reads translated

It is probably transcreated, not native-reviewed. Ask the agent which locales you can read and review those. Never ask a non-native to sign off.

Match a Set

Found screenshots you love? The agent measures them, it does not guess.

What it takes

Composition, margins, baselines, type scale, tracking, palette relationships, device scale, depth and the rhythm across the set.

What it never takes

The other brand, its copy, icons, photography or app UI. Your app and your content go in their place.

Asset Library

Atmosphere from Higgsfield. Precise UI stays code.

Generate

3D clay glyphs for pill tiles, objects that fit your app, stickers, hands holding a plain slab, a scene or light behind a device, glow around a real card.

Never generate

Readable UI, tables, figures, buttons, any text or numbers, Apple hardware, logos, real brands, real people, proportion-critical chrome like a search bar.
